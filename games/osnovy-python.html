Урок 1. Привіт, Python! 👋

🎯 Сьогодні ти навчишся: запускати програму і виводити на екран текст та числа.

Програма — це список інструкцій для комп'ютера, як рецепт для кухаря. Комп'ютер виконує їх по черзі, зверху вниз.

Python — мова програмування. Назву взяли з комедійного шоу, але її символ — змійка 🐍.

Команда print

Команда print() показує на екрані те, що написано в дужках. Текст обов'язково беремо в лапки, а числа — без лапок.

Знаки дій у Python

ДіяЗнакПриклад
Додавання+print(5 + 2) → 7
Віднімання-print(5 - 2) → 3

Ділення/print(10 / 2) → 5.0

Урок 2. Змінні — коробочки для даних 📦

🎯 Сьогодні ти навчишся: зберігати дані у змінних і рахувати з ними.

Змінна — це коробочка з наліпкою-назвою. У коробочку можна покласти число або текст, а потім дістати його за назвою.

Знак = означає «поклади в коробочку». Наприклад, age = 10 — поклади число 10 у коробочку з назвою age.

💡 Кому в print використовуємо, щоб вивести кілька речей підряд. Python сам поставить між ними пробіл.

Правила назв змінних

  • Пиши латинськими літерами: name, cats, my_age.
  • Без пробілів — замість пробілу знак _.
  • Не можна починати з цифри: 2cats — ❌, cats2 — ✅.

Задачка про цукерки 🍬

✏️ Завдання

  1. Створи змінні animal та color зі своєю улюбленою твариною і кольором. Виведи речення: «Мій улюблений звір — ..., а колір — ...».
  2. У класі 14 дівчат і 13 хлопців. Збережи їх у змінні й порахуй, скільки всього учнів.
  3. Яблуко коштує 8 гривень. Порахуй, скільки коштують 6 яблук.
❓ Яка назва змінної правильна?
👩‍🏫 Для вчителя Гарна аналогія — підписані коробки на столі. Можна покласти у «коробку» нове значення: age = 11. Поясніть різницю між "10" (текст) і 10 (число): print("10" + "10") дасть 1010.

Урок 3. Розмова з комп'ютером 💬

🎯 Сьогодні ти навчишся: запитувати в користувача відповіді за допомогою input().

Команда input() ставить запитання і чекає, поки ти введеш відповідь. Відповідь можна покласти у змінну.

💡 Коли програма запитає — під кодом з'явиться жовте поле. Введи відповідь і натисни Enter.

Числа з input

input() завжди повертає текст. Щоб рахувати, текст треба перетворити на число командою int():

⚠️ Без int() Python не зможе додати число до тексту і покаже помилку.

✏️ Завдання

  1. Калькулятор: запитай два числа і виведи їхню суму, різницю та добуток.
  2. Чат-бот: напиши програму, яка ставить 3 запитання (ім'я, улюблена тварина, хобі) і відповідає на кожне.
❓ Навіщо потрібна команда int()?
👩‍🏫 Для вчителя Учні дуже люблять «чат-бота» — дайте можливість обмінятися комп'ютерами й поспілкуватися з ботом сусіда. Якщо учень вводить літери замість числа в int(input()) — буде ValueError, гарний привід поговорити про помилки.

Урок 4. Черепашка-художник 🐢

🎯 Сьогодні ти навчишся: малювати за допомогою черепашки.

У Python живе черепашка, яка вміє малювати! Вона повзає по екрану і залишає слід. Ми даємо їй команди — вона виконує.

Команди черепашки

КомандаЩо робить
t.forward(100)Іти вперед на 100 кроків
t.back(50)Іти назад на 50 кроків
t.left(90)Повернути ліворуч на 90°
t.right(90)Повернути праворуч на 90°
t.color("red")Змінити колір
t.pensize(5)Товщина лінії
t.penup() / t.pendown()Підняти / опустити олівець
t.circle(50)Намалювати коло радіусом 50

Кольори англійською: red, blue, green, yellow, orange, purple, pink, black.

✏️ Завдання

  1. Намалюй квадрат (4 сторони, кожен поворот на 90°).
  2. Намалюй трикутник (підказка: повертати треба на 120°).
  3. Намалюй сонечко: жовте коло товстим олівцем.
❓ На скільки градусів треба повертати, щоб намалювати квадрат?
👩‍🏫 Для вчителя Перед кодом можна пограти «в черепашку» фізично: один учень — черепашка, інші дають команди «вперед 3 кроки, ліворуч». Учні помітять, що для квадрата повторюємо одне й те саме 4 рази — це місток до наступного уроку про цикли.

Урок 6. Якщо... інакше 🤔

🎯 Сьогодні ти навчишся: робити так, щоб програма приймала рішення.

У житті ми постійно приймаємо рішення: якщо йде дощ — беру парасольку, інакше — кепку. У Python для цього є if (якщо) та else (інакше).

Знаки порівняння

ЗнакЗначення
==дорівнює
!=не дорівнює
>більше
<менше
>=більше або дорівнює
<=менше або дорівнює
⚠️ Не плутай! Один знак = — «поклади в змінну». Два знаки == — «перевір, чи дорівнює».

  3. ⭐ Запитай число і скажи, парне воно чи ні (підказка: number % 2 == 0 — означає, що число ділиться на 2 без остачі).

👩‍🏫 Для вчителя Звертайте увагу, що порівняння тексту точне: «київ» з малої літери не дорівнює «Київ». Це гарна тема для обговорення. Учні можуть обмінятися вікторинами з сусідом.
